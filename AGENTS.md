# Path of Building PoE2 — AI Instructions

Прочитай `docs/ai/START_HERE.md` перед началом работы.

Основной язык общения — русский.
Язык исходного кода и идентификаторы сохранять.

Это основной репозиторий приложения в workspace PoB2Fork.
Его соседние проекты RePoE, PyPoE и SimpleGraphic являются отдельными Git-репозиториями.

Обязательные правила:
- Проверяй git status до и после работы.
- Не перезаписывай существующие пользовательские изменения.
- Не выполняй reset, clean, commit или rebase без разрешения.
- Изучи связанные участки кода перед проектированием изменений.
- Сохраняй обратную совместимость, если иное не согласовано.
- Проверяй реальные API и версии зависимостей.
- При необходимости изменения соседних компонентов рассматривай их как отдельные задачи и отдельные Git-репозитории.
- Обновляй docs/ai при изменении архитектуры, статуса или технических решений.
